# DailySnap

DailySnap 是一个面向个人工作记录的桌面助手：
- 定时轻提醒你记录进展
- 用最短输入完成碎片记录
- 自动整理当日时间线与日报

> 当前版本强调：极简、少打扰、悬浮交互优先。

## 这个产品现在能做什么

- **悬浮球提醒记录**：默认常驻桌面角落，不强打断。
- **一键进入快速输入**：看到提醒后可直接展开输入并发送。
- **AI 追问补全**：必要时最多追问 3 轮，帮助补齐上下文。
- **时间线查看**：按时间回看当天记录。
- **日报生成**：基于当日记录自动整理日报内容。
- **本地设置持久化**：提醒与 API Key 保存到本地数据库。

## 使用流程（用户视角）

### 1) 首次打开后先设置
进入主窗口的“设置”页，配置：
- 提醒开始时间
- 提醒周期（含“每 30 秒（测试）”）
- 日报生成时间
- 是否节假日关闭提醒
- API Key

配置后点击 **保存设置**。

### 2) 日常记录怎么用
- 到点后，悬浮球会出现提醒（红点/提示条）。
- 点击提示条或点击悬浮球可进入输入态。
- 输入一句当前进展，按 **Enter 发送**（Shift+Enter 换行）。
- 如触发追问，按提示补充；也可点击“结束追问”。

### 3) 查看结果
- 在“时间轴”查看当天记录。
- 在“日报”查看自动整理内容并复制使用。

## 悬浮交互说明（当前版本）

DailySnap 悬浮区有 3 个状态：
- **compact**：仅悬浮球
- **hint**：悬浮球旁提示条
- **expanded**：输入区（快捷按钮 + 输入框 + 发送）

关键行为：
- 单击悬浮球：在 compact/hint/expanded 之间按规则切换
- 双击悬浮球：打开主窗口
- 有未读提醒时：悬浮球右上角显示红点
- 提示条支持手动关闭，不影响悬浮球常驻

## 你可能关心的几个问题

### 为什么我点了保存但感觉没生效？
设置采用“本地落库 + 回读校验”机制。若失败会在设置页显示错误信息；看到“设置已保存 ✓”才表示本地保存成功。

### 我想快速测试提醒是否工作
把提醒周期设置为 **每 30 秒（测试）**，保存后观察悬浮提醒是否按预期出现。

### 主窗口关掉后去哪了？
关闭主窗口会最小化到悬浮球，不会退出应用。
