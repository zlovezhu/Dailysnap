# DailySnap 交互规格冻结文档 v0.9

日期：2026-06-12  
状态：已确认（可进入实现）

## 1. 目标与边界

本版本目标：先把核心交互跑顺，减少状态冲突与误触，保证提醒-记录-追问链路可预测。

本版本不做：
- 错过提醒后的独立“补录入口”
- 红点数量显示
- 复杂动画与多级确认弹窗

---

## 2. 状态定义

- `MAIN`：主窗口可见
- `COMPACT`：仅悬浮球
- `HINT`：提示态（文案 + 最近5条）
- `EXPANDED`：输入态（输入框 + 快捷按钮 + 发送 + 结束追问）
- `FOLLOWUP_ACTIVE`：追问进行中（逻辑态，可叠加在 EXPANDED）

---

## 3. 全局可见性与入口规则

1. 启动：`MAIN` 可见，悬浮球隐藏。
2. 主窗口关闭：进入 `COMPACT`。
3. 双击悬浮球：打开 `MAIN`，销毁悬浮视觉态（仅保留数据）。
4. 仅 `COMPACT` 态单击悬浮球进入 `HINT`。
5. 在 `HINT/EXPANDED` 态单击悬浮球本体：收起回 `COMPACT`。
6. 拖拽阈值：鼠标位移 > 6px 才判定拖拽。

---

## 4. 提醒触发与补触发规则

### 4.1 正常触发
- `MAIN` 打开时：不切悬浮提示，改为主窗口顶部轻提示。
  - 自动消失：5 秒
  - 点击行为：聚焦对话输入框
  - 5 秒内重复触发：只保留一条并刷新计时

- `MAIN` 关闭时：走悬浮链路（`COMPACT -> HINT`）

### 4.2 追问期间触发
- 追问进行中不打断输入，不立即弹提示。
- 追问结束后补触发：按错过次数逐条补。
- 补触发节奏：3 秒/条。
- 补触发上限：最多 3 条。
- 若补触发进行中用户手动进入记录流程：立即取消剩余补触发。

---

## 5. HINT 交互规则

1. 文案来源：动态文案；当手动单击进入时使用兜底文案（与常规提醒区分）。
2. 关闭按钮：hover 才显示，点击仅关闭本次提示。
3. 自动消失：5 分钟；hover/输入期间暂停计时，离开后继续。
4. 最近记录展示：
   - 来源：当日全部记录（与主窗口口径一致）
   - 条数：最近 5 条
   - 排序：时间正序（最新在最下）
   - 时间格式：`HH:mm`
   - 文本截断：约 24 字
   - 超出占位：顶部显示 `...`，仅提示不可点击

5. 红点规则：
   - 仅显示有/无，不显示数量
   - 用户点开 `HINT` 即清除红点

---

## 6. EXPANDED 与输入规则

1. `HINT` 点击提示区进入 `EXPANDED`。
2. 快捷按钮：仅填入输入框，不自动发送。
3. 快捷填入后光标位置：文本末尾。
4. 键盘行为：`Enter` 发送，`Shift+Enter` 换行。
5. 发送成功反馈：不额外显示“已记录”提示文案，仅列表更新。
6. 草稿策略：从 `EXPANDED` 收起到 `COMPACT` 时保留草稿。

---

## 7. 追问（Follow-up）规则

1. 最大追问轮数：默认 3，用户可配置。
2. 是否继续追问：由 AI 判断，但不得超过最大轮数。
3. 追问结束条件（任一满足）：
   - 用户回答最后一条追问并发送成功
   - 用户点击“结束追问”按钮
4. “结束追问”按钮位置：`EXPANDED` 右上角。
5. 点击“结束追问”：立即结束，不二次确认。
6. 达到最大轮数仍需继续时：强制收束并回到 `HINT`。
7. 追问中显示轮次：如 `追问 1/3`。

---

## 8. 状态机（事件表）

| 当前状态 | 事件 | 条件 | 下一状态 | 备注 |
|---|---|---|---|---|
| MAIN | 关闭主窗口 | - | COMPACT | 主窗口隐藏 |
| MAIN | 到点提醒 | - | MAIN | 顶部轻提示 5 秒 |
| COMPACT | 单击悬浮球 | 非拖拽 | HINT | 清红点 |
| COMPACT | 双击悬浮球 | 非拖拽 | MAIN | 销毁悬浮视觉态 |
| HINT | 点击提示区 | - | EXPANDED | 进入输入 |
| HINT | 点击关闭按钮 | - | COMPACT | 仅关闭本次 |
| HINT | 超时 | 非 hover/输入 | COMPACT | 5 分钟+渐隐 |
| HINT | 单击球体 | - | COMPACT | 收起 |
| EXPANDED | 发送成功 | 非追问结束 | EXPANDED/HINT* | 由追问逻辑决定 |
| EXPANDED | 点击结束追问 | - | HINT | 立即结束 |
| EXPANDED | 单击球体 | - | COMPACT | 保留草稿 |
| FOLLOWUP_ACTIVE | 到点提醒 | - | FOLLOWUP_ACTIVE | 仅累计错过数 |
| FOLLOWUP_ACTIVE 结束 | - | 有错过提醒 | HINT（补触发） | 最多3条，3秒间隔 |

> 注：`EXPANDED/HINT*` 表示当轮输入后是否继续追问由 AI + 轮次上限共同决定。

## 9. 原型验收清单（可勾选）

### 9.1 可见性与基础操作
- [ ] 启动后仅主窗口可见
- [ ] 关闭主窗口后回到 compact
- [ ] 双击悬浮球可打开主窗口并隐藏悬浮态
- [ ] 拖拽阈值 >6px 才触发拖拽

### 9.2 提醒链路
- [ ] 主窗口打开时，到点提醒为顶部轻提示（5秒）
- [ ] 轻提示点击可聚焦输入框
- [ ] 5秒内重复提醒只保留一条并刷新计时

### 9.3 HINT 细节
- [ ] compact 单击进入 hint
- [ ] hint/expanded 单击球体收起 compact
- [ ] hover 才显示关闭按钮
- [ ] 关闭按钮仅关闭本次提示
- [ ] hint 5分钟自动消失，hover/输入时暂停
- [ ] 最近5条来自当日全部记录，正序+HH:mm
- [ ] 超出显示 `...` 且不可点击
- [ ] 每条约24字截断

### 9.4 输入与追问
- [ ] 快捷按钮仅填充，不自动发送
- [ ] 快捷填充后光标在末尾
- [ ] Enter 发送 / Shift+Enter 换行
- [ ] 发送后无额外“已记录”提示
- [ ] 结束追问按钮在 expanded 右上角
- [ ] 结束追问立即生效（无二次确认）
- [ ] 追问轮次显示正确（如 1/3）
- [ ] 达上限强制收束并回 hint

### 9.5 追问与补触发
- [ ] 追问期间提醒不打断输入
- [ ] 追问结束后按错过次数补触发
- [ ] 补触发间隔 3 秒/条
- [ ] 补触发最多 3 条
- [ ] 用户手动进入记录后，剩余补触发被取消

## 10. 实施顺序建议

1. 先改状态机与事件路由（不动样式）  
2. 再改追问逻辑与提醒避让  
3. 最后做视觉微调与动画（渐隐）  
4. 每步都跑回归清单，防止状态回归
